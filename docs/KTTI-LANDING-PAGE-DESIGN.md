# KTTI Ads Landing Page — Design & Content Spec

> **উদ্দেশ্য:** Facebook/Google বিজ্ঞাপন থেকে আসা ভিজিটরকে কোর্স দেখিয়ে সরাসরি রেজিস্ট্রেশন করানো।  
> **ভাষা:** পুরো পেজ বাংলা। **ডিজাইন:** মোবাইল-ফার্স্ট।  
> **স্ট্যাক মিল:** বিদ্যমান `frontend` (Next.js) ব্র্যান্ড — `#A71728`, Anek Bangla, square (`border-radius: 0`) বাটন / DoorButton।

## ১. এই ডকুমেন্ট কীভাবে ব্যবহার করবেন

| কে | কী করবেন |
|---|---|
| **ওয়েব ডেভেলপার** | নিচের সেকশন অর্ডার, অ্যাঙ্কর, ফর্ম ফিল্ড ও সাবমিশন নিয়ম অনুযায়ী পেজ বানাবেন |
| **ডিজাইনার** | সেকশন ওয়্যারফ্রেম + ভিজ্যুয়াল নোট অনুযায়ী মকআপ করবেন |
| **মার্কেটিং** | অ্যাঙ্কর লিংক বিজ্ঞাপনে বসাবেন; রিল স্ক্রিপ্ট (সেকশন ১১) অনুযায়ী ভিডিও কাটবেন |
| **কন্টেন্ট/অ্যাডমিন** | `[PLACEHOLDER]` জায়গায় ঠিকানা, WhatsApp, ইমেইল, Facebook লিংক পূরণ করবেন |

### প্রস্তাবিত রাউট (Next.js)

```
/landing/japanese-register   বা   /bn/register
```

- এটি **স্ট্যান্ডঅ্যালোন অ্যাডস ল্যান্ডিং** — মূল হোম (`/`) থেকে আলাদা রাখা ভালো, যাতে বিজ্ঞাপনের কনভার্সন পরিষ্কার থাকে।
- নেভিগেশন মিনিমাল: লোগো + WhatsApp + “কোর্স দেখুন”।
- সাইটের বিদ্যমান `ApplyModal` ব্যবহার না করে **প্রতিটি প্যাকেজের ইনলাইন ফর্ম** ব্যবহার করুন।

### ভিজ্যুয়াল নোট (মোবাইল-ফার্স্ট)

1. **এক কম্পোজিশন হিরো:** ব্র্যান্ড (KTTI) + H1 + ১ সাবলাইন্ + ২ CTA। স্ট্যাট/কার্ড/প্রোমো স্টিকার হিরোতে নয়।
2. **হিরো মিডিয়া:** ফুল-ব্লিড ব্যাকগ্রাউন্ড (ক্লাসরুম/জাপান অ্যাটমোস্ফিয়ার) + হালকা ডার্ক ওভারলে যাতে বাংলা টেক্সট পঠনযোগ্য হয়।
3. **প্যাকেজ ব্লক:** কার্ড শুধু যেখানে ইন্টারঅ্যাকশন আছে (শিফট সিলেক্ট, ফর্ম)। বর্ণনা সাধারণ টেক্সট ব্লক।
4. **মোশন (২–৩টি):** (ক) হ্যাশে স্ক্রল স্মুথ, (খ) সাকসেস স্টেট ফেড-ইন, (গ) নন-রেসিডেনশিয়াল স্টেপ ট্রানজিশন।
5. **ভায়োলেট/ক্রিম টেমপ্লেট এড়িয়ে চলুন** — সাইটের লাল–কালো–সাদা ভাষা রাখুন।

## ৪. সেকশন-ওয়াইজ কনটেন্ট

### A. Hero `#hero`

| এলিমেন্ট | কপি |
|---|---|
| Brand | KTTI · Kawaii Group |
| H1 | জাপানে যেতে চান? জাপানি ভাষা শিখুন KTTI-তে |
| সাব | Kawaii Group-এর জাপানি ভাষা প্রশিক্ষণ প্রতিষ্ঠান। সাপ্তাহিক মক টেস্ট, মক ইন্টারভিউ ও SSW ভিত্তিক দক্ষতা উন্নয়নসহ আপনার জাপান যাত্রার পূর্ণ প্রস্তুতি। |
| CTA ১ | আমার পছন্দের কোর্স দেখুন → `#packages` |

### A2. Intro (হিরোর নিচে)

জাপানে কাজ বা পড়াশোনা করতে চাইলে জাপানি ভাষা জানা সবচেয়ে বড় প্রস্তুতি। KTTI (Kawaii Trading Training Institute) হলো Kawaii Group-এর জাপানি ভাষা প্রশিক্ষণ প্রতিষ্ঠান। Kawaii Group বাংলাদেশ ও জাপানের যৌথ উদ্যোগে গড়া একটি কোম্পানি। আমাদের এখানে আপনি জাপানি ভাষা শিখতে পারবেন আবাসিক, অনাবাসিক বা অনলাইনে, নিজের সময় ও সামর্থ্য অনুযায়ী। শুধু ক্লাসই নয়, প্রতি সপ্তাহে মক টেস্ট, জাপান থেকে পরিচালিত মক ইন্টারভিউ এবং জাপানি সংস্কৃতির পাঠ আপনাকে আসল ইন্টারভিউয়ের জন্য আত্মবিশ্বাসী করে তুলবে।

### B. Visa `#visa`

**শিরোনাম:** জাপানে যাওয়ার ভিসা ক্যাটাগরি

| ক্যাটাগরি | সংক্ষিপ্ত ব্যাখ্যা |
|---|---|
| স্টুডেন্ট ভিসা | জাপানে পড়াশোনার জন্য |
| SSW (Specified Skilled Worker) | নির্দিষ্ট খাতে দক্ষ কর্মী হিসেবে কাজের জন্য |
| ESDP | কাজের মাধ্যমে দক্ষতা উন্নয়নের কর্মসূচি |
| Engineer / Specialist… | ইঞ্জিনিয়ার ও বিশেষজ্ঞ পেশাজীবীদের জন্য |

**যাচাই ব্লক (ভিসার নিচে):**

- শিরোনাম: আগে নিজেকে যাচাই করুন, মাত্র 2,500 টাকায়
- বডি: KTTI-তে রেজিস্ট্রেশন করে 2,500 টাকা টিউশন ফি দিলে প্রত্যেক প্রার্থী নিজের প্রস্তুতি যাচাই করতে পারেন। যারা হোস্টেলে থাকতে চান, ১৫ দিনের জন্য আরও 5,000 টাকা।
- লিংক বাটন: বেসিক কোর্সে রেজিস্ট্রেশন → `#basic`

### C. Benefits `#benefits`

**শিরোনাম:** KTTI-তে কোর্স করলে বাড়তি যা যা পাবেন

1. সাপ্তাহিক মক টেস্ট  
2. মক ইন্টারভিউ (জাপান থেকে পরিচালিত)  
3. জাপানি সংস্কৃতির পাঠ  
4. SSW ভিত্তিক দক্ষতা উন্নয়ন  
5. সাপ্তাহিক কথোপকথন ক্লাস  

**ফুটনোট:** যারা মক ইন্টারভিউতে উত্তীর্ণ হন, শুধু তাদের জন্যই আমরা আসল ইন্টারভিউয়ের ব্যবস্থা করে থাকি।

### ক. বেসিক কোর্স `#basic`

**H3:** ২,৫০০ টাকার বেসিক জাপানি ভাষা কোর্স (১৫ দিন)

**বর্ণনা (বুলেট):**
- জাপানি ভাষা আপনার জন্য সহজ হবে কি না, পুরো কোর্সে ভর্তির আগে যাচাই
- মাত্র ১৫ দিনের বেসিক ক্লাস
- ১৫ দিন শেষে নিজেই বুঝবেন শিখতে পারবেন কি না
- আগে যাচাই, তারপর পুরো কোর্সের সিদ্ধান্ত
- আবাসিক বা অনাবাসিক — দুইভাবেই করা যায়
- জাপান যাত্রার প্রথম ধাপ

**সময় ও খরচ:**

| আইটেম | মান |
|---|---|
| মেয়াদ | ১৫ দিন |
| অনাবাসিক | 2,500 টাকা |
| আবাসিক (হোস্টেলসহ) | 2,500 + 5,000 = **7,500 টাকা** |

**ফর্ম ক**

| ফিল্ড | টাইপ | বাধ্যতামূলক |
|---|---|---|
| নাম | text | হ্যাঁ |
| ঠিকানা | text / textarea | হ্যাঁ |
| ফোন নম্বর | tel | হ্যাঁ (১১ ডিজিট `01XXXXXXXXX`) |
| প্যাকেজ অপশন | radio | হ্যাঁ — `অনাবাসিক (2,500 টাকা)` / `আবাসিক (7,500 টাকা)` |

### খ. আবাসিক কোর্স `#residential`

**H3:** আবাসিক কোর্স (৬ মাস)

**বর্ণনা:** ৬ মাসের পূর্ণ আবাসিক কোর্স; হোস্টেলে থেকে পড়া; থাকা–খাওয়া ফি-এর মধ্যে; ভাষার পরিবেশে দ্রুত শেখা; মক টেস্ট/ইন্টারভিউ/সংস্কৃতি অন্তর্ভুক্ত; দূরের বা পূর্ণ মনোযোগের জন্য সেরা।

**সময় ও খরচ:** মেয়াদ ৬ মাস · **150,000 টাকা** (খাওয়া ও থাকাসহ, নন-রিফান্ডেবল)

**ফর্ম খ:** নাম, ঠিকানা, ফোন।

**বর্ণনা:** বাসা থেকে এসে ক্লাস; সকাল/দুপুর/সন্ধ্যা শিফট; N5, N4 ও SSW Skill; চাকরি/পড়ার পাশাপাশি; মক টেস্ট ও কথোপকথন প্রতি প্যাকেজে।

#### Wizard ধাপ

ধাপ ১ → শিফট বাছুন (কার্ড/রেডিও)

## ৬. ফর্ম ভ্যালিডেশন ও সাবমিশন

### কমন রুলস

- সব লেবেল **বাংলায়**
- ফোন: রেজেক্স `^01[3-9]\d{8}$` (১১ ডিজিট)
- মোবাইলে বড় টাচ টার্গেট (`min-h-12`), `inputmode="numeric"` ফোনে
- সাকসেস মেসেজ: **ধন্যবাদ! আমাদের প্রতিনিধি শীঘ্রই আপনার সাথে যোগাযোগ করবেন।**
- স্প্যাম: honeypot ফিল্ড + (ঐচ্ছিক) reCAPTCHA v3
- সাবমিট ডিজেবল যতক্ষণ সাবমিটিং

### প্রতিটি সাবমিশনের সাথে যাবে

| কী | উদাহরণ |
|---|---|
| `form_name` | `basic` / `residential` / … |
| `package_name` | `সকাল · N5` বা `আবাসিক ৬ মাস` |
| `submitted_at` | ISO datetime (Asia/Dhaka) |
| `utm_source`, `utm_medium`, `utm_campaign`, `utm_content` | URL থেকে |
| `landing_url` | পূর্ণ URL + hash |
| ফর্ম ফিল্ডসমূহ | নাম, ফোন, … |

### ব্যাকএন্ড টার্গেট (যেকোনো এক বা দুইটি)

1. **Google Sheet** (Apps Script webhook) — দ্রুত লঞ্চ  
2. **অ্যাডমিন ড্যাশবোর্ড API** — স্থায়ী  
3. **নোটিফিকেশন:** ইমেইল এবং/অথবা WhatsApp (অ্যাডমিন নম্বরে)

প্রস্তাবিত API শেপ:

```ts
POST /api/landing/register
{
  form_name: "non-residential",
  package_name: "সকাল · N5",
  name: "...",
  address: "...",
  phone: "01XXXXXXXXX",
  // ...form-specific
  utm: { source, medium, campaign, content },
  honeypot: ""
}
```
